# Exercise pack 1 — first steps

Eight exercises, four per language. Each one runs fully inside Warsha: console output and typed
input only. No files, no internet, no extra libraries.

Do them in order. Each exercise assumes the one before it.

| # | Java | Python | New idea |
|---|------|--------|----------|
| 01 | [java-01-hello-and-variables.md](java-01-hello-and-variables.md) | [python-01-hello-and-variables.md](python-01-hello-and-variables.md) | Print, variables, read one line |
| 02 | [java-02-conditionals-and-loops.md](java-02-conditionals-and-loops.md) | [python-02-conditionals-and-loops.md](python-02-conditionals-and-loops.md) | `if` / `else`, loops, repeat until the user stops |
| 03 | [java-03-methods.md](java-03-methods.md) | [python-03-functions.md](python-03-functions.md) | Methods and functions: arguments and return values |
| 04 | [java-04-two-class-oop.md](java-04-two-class-oop.md) | [python-04-class-and-module.md](python-04-class-and-module.md) | Two classes, a folder of your own, one override |

**How each file is shaped:** goal, starter code to paste in, numbered tasks, the exact output you
should get, one hint, and one stretch task for students who finish early.

The expected output blocks show a real session. Where the program asks a question, the answer the
student typed is shown on the same line, exactly as it looks in the console panel.

Exercises 01 to 03 need only the one file `app/Main.java` or `main.py`. Exercise 04 asks the student
to create a second folder, which is the first time the file tree matters.
